# Example configs

Copy one to `~/.config/herdr-router/routing.toml` and edit the model names.

| File | For |
|---|---|
| `claude-and-codex.toml` | One Claude and one Codex subscription |
| `two-claude-accounts.toml` | A personal and a work Claude login |
| `three-subscriptions-capped.toml` | Claude + Codex + Antigravity, mid-range models only |

Every file here is checked by the test suite, so they always parse.
